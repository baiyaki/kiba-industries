# KIBA Industries logo kit

**svg/** (sharp at any size; use these for print, signs, websites and design apps)
- `kiba-industries-horizontal-*`: the K, a line, then KIBA / INDUSTRIES. The main logo.
- `kiba-stacked-*`: the K above KIBA, for square spaces.
- `kiba-mark-*`: the K alone, for small places.
- `kiba-app-icon.svg`: the dark rounded icon. `kiba-app-icon-square.svg`: the same without rounded
  corners, for app stores and social profile pictures (they round it themselves).
- `-white` goes on dark backgrounds, `-black` on light ones.

**png/** (transparent backgrounds; the number is the width or longest side in pixels)
- Use these where SVG isn't accepted (Word, WhatsApp, Canva, email signatures).

Fonts used: Michroma (KIBA) and Montserrat (INDUSTRIES), both free (SIL Open Font License).
The letters are turned into shapes in the files, so nobody needs the fonts installed.
Leave space around the logo about the width of one bar of the K, and don't stretch or recolour it.
